# 联合校正共享标定误差求解器（纯后端、精确有理数）

实验平台中，测量值 = 真实量的线性组合 + 共享标定偏差。逐条去偏会破坏守恒关系，
而缺测又可能让真实量不唯一。本工具在**同时满足全部测量方程与守恒式**的前提下，
按严格的两层字典序目标求解，全程使用 `fractions.Fraction` 精确运算，
不做任何浮点近似，也不调用任何代数或优化求解库。

## 目标（两层，不加权合成）

1. 第一层：在所有可行解中最小化 `Σ z²`（共享偏差能量）；
2. 第二层：在第一层的全部最优解中最小化 `Σ x²`（真实量能量，**缺测变量同样计入**）。

两层是字典序关系：先第一层、再第二层，绝不合并成单一加权目标。

## 输入格式（UTF-8 JSON）

```json
{
  "variables":   ["x", "y"],
  "noises":      ["z"],
  "observations": [
    {
      "id": "o1",
      "value": "3/1",
      "terms":       {"x": "1/1"},
      "noise_terms": {"z": "1/1"}
    }
  ],
  "balances": [
    {"id": "b1", "terms": {"x": "1/1", "y": "1/1"}, "value": "6/1"}
  ]
}
```

- `variables`：真实量标识；`noises`：独立误差标识。标识为非空 ASCII 字母数字串，
  各自集合内唯一，且两类标识互不重叠（分属不同空间）。
- 测量：`value = Σ terms·x + Σ noise_terms·z`。同一误差标识在任意测量中出现，
  都对应**同一个** `z` 分量（共享偏差）。
- 守恒式：`Σ terms·x = value`，只能引用真实量；其 `id` 与测量 `id` 全局唯一。
- 所有数值都是 `p/q` 字符串：`p` 为整数、`q` 为**正**整数。空数组、空系数对象合法，
  未列出的系数视为 0，所有引用必须存在。

### 严格校验（拒绝并定位路径）

以下情况一律拒绝，错误信息带 `$.field[i].sub` 形式的 JSONPath 定位：
重复 JSON 字段、未知字段、缺失字段、类型错误、非法 `p/q`（含浮点、零/负分母）、
非法标识、悬空引用、测量/守恒 `id` 冲突等。非法输入不会产生或替换输出。

## 输出格式

成功（`status: "optimal"`），按标识排序：

```json
{
  "status": "optimal",
  "x": {"x": "2/1", "y": "4/1"},
  "z": {"z": "1/1"},
  "corrected": {"o1": "2/1", "o2": "4/1", "o3": "6/1"},
  "objectives": {"sum_z_squared": "1/1", "sum_x_squared": "20/1"}
}
```

- `corrected` 是逐测量的校正值 `Σ terms·x`（**不含**噪声项）。
- 所有数值均为约分后正分母的 `p/q`。

无解（`status: "infeasible"`）：不返回校正值，给出**原始等式的有理数线性组合
证书**，使未知量系数全部消为 0、右端恰为 1：

```json
{
  "status": "infeasible",
  "certificate": {"b1": "1/1", "o1": "-1/2", "o2": "-1/2"}
}
```

## 运行方式

推荐隔离模式（`-I` 忽略环境中的 `PYTHONPATH`/用户站点包，避免同名模块注入）：

```bash
python3 -I run_calibration.py 输入.json                 # 结果打印到标准输出
python3 -I run_calibration.py 输入.json 输出.json       # 原子写入输出文件
```

也支持包方式：

```bash
python3 -m joint_calibration 输入.json [输出.json]
python3 -I joint_calibration/__main__.py 输入.json
```

写入输出文件时，先写同目录临时文件再 `os.replace` **原子替换**；只有完整解析、
校验、求解成功后才替换，任何失败都保留旧结果。退出码：成功 `0`，输入/IO 错误 `1`，
用法错误 `2`。

## 实现组织

输入校验与有理数解析在 `model.py`、`strict_json.py`；`solver.py` 用带等式来源信息的
消元检查一致性，保留可行解及方向信息，再执行误差坐标与真实量坐标的投影计算。
不可行证书来自消元过程，文件入口负责完整结果的原子写出。输出须满足上面的两层目标。

## 验收

```bash
python3 -I tests/run_acceptance.py
```

测试独立实现了一套 RREF/零空间/KKT 核对（不复用求解器内部函数），覆盖：

- 规范核对 `x+z=3、y+z=5、x+y=6` ⇒ `x=2、y=4、z=1`；
- 共享误差、冗余等式、矛盾守恒、矛盾测量、缺测变量归零、乱序输入、空输入；
- 独立的两层最优性 KKT 核对，以及分数步长网格暴力枚举确认全局最优；
- 无解证书的独立复算（系数全零、右端为 1），含跨测量/守恒的混合证书；
- 严格校验的各类拒绝路径与定位信息；
- 原子输出：成功才替换、非法输入保留旧结果、无临时文件残留；
- 180 组固定随机种子的随机系统（一致系统验两层最优、矛盾系统验证书）。

## 目录结构

```
joint_calibration/
  strict_json.py   严格 JSON 解析（拒绝重复字段，带定位）
  model.py         模式校验、p/q 解析、数据模型
  solver.py        RREF、不可行证书、两层最小二乘
  __main__.py      CLI 与原子输出
run_calibration.py 隔离模式顶层入口
examples/          规范、共享误差、不可行示例
tests/             独立验收测试
```
